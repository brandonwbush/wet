# 💦 Welcome to the WET Codebase
Thank you for your interest in contributing to this majestic swamp of software.

## 🚧 Coding Guidelines

To ensure maximum dampness:

- Avoid abstraction. If you think "this could be a shared function," immediately stop and duplicate it instead.
- Variable names should be long, inconsistent, and reused inappropriately across scopes.
- Copy-paste with reckless abandon, especially from Stack Overflow answers that "kinda work."
- Each contributor is encouraged to reinvent the wheel — ideally with square edges.

## 🧪 Testing
- Manual testing only. Automated tests are suspiciously DRY.
- If you must test, do it once, vaguely.
- Never write a test that could fail in CI — failure implies dryness.

## 🧻 Documentation
- Out-of-date and copy-pasted from unrelated modules? Perfect.
- Update it only if you've already updated the same doc elsewhere.

## 📬 Pull Requests
- Include no fewer than 3 identical functions.
- Bonus points if they behave differently.
- Include unrelated changes in each PR to ensure maximum confusion.
